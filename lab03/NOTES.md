Сравнение версий и поиск изменений файла
git diff  показывает различие между версиями файлов
git show показывает информацию о конкретном коммите
git log показывает историю коммитов
log -S ничего не выдало, потому что я не использовал функцию def
blame показало все строчки в файле

Отличия git restore от git restore --source=...
git restore берет версию файла из последнего коммита и восстанавливает в рабочую директорию
git restore --source=... указывает, из какого коммита или ветки взять версию
